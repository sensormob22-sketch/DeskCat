# Native Tripo3D GLB transfer — experimental

Source supplied by the user: `calico cat 3d model new.glb` (SHA-256 `b9e6eddf47cd01009b1f0137b45bc002192cd9e44fba1c6d297a2afba2395b1f`).

## Verified compatibility

- Original Tripo export: 19,464 vertices, 16,460 triangles, 4096×4096 basecolor JPEG and 2048×2048 normal PNG.
- Export contains 21 nominal joints but almost every vertex is rigidly assigned to a single joint. No animation channels are present; this is not an animated rig.
- Every original vertex matches a vertex in the **main** DeskCat Stage20 mesh to within `2.82e-7` source units (normals also match). It is therefore unnecessary to remesh/reconstruct the user's new cat.
- The local offline converter `rig_new_tripo.py` matches by geometry, transfers Stage20's 25-joint skeleton, inverse bind matrices, skin weights, and idle/walk tracks, and preserves original Tripo `POSITION`, `NORMAL`, `TEXCOORD_0`, indices, basecolor, and normal image bytes.
- Result: 25 joints, `idle` and `walk` with 5 and 20 channels respectively. Generated candidate SHA-256 `3ad6dd313a312c4fd8e21eb7d7e8114fafd701c840f2ed8dcbeba6c07bd0ffe0`.
- Native GLB size approximately 14.9 MB. The existing Python/Qt/Panda3D launcher can use it by replacing `assets/3d/deskcat_belly_skinned_trial.glb` **inside a separate test build**, without changing code.

## Important limitations

The transferred rig still inherits some deformation problems. Offline CPU skinning showed right-hind lower-leg triangle-edge elongation beyond 3× at extreme poses. The preview is a test candidate, **not a verified natural walk**. The original old curved belly patch is *not* transferred; inspect the underside on Windows as well. The source coat and tail textures are unchanged.

A test Windows ZIP with the new rigged binary and the offline converter was produced during the user's chat. The binary source/derived file are not committed to GitHub; this document alone does not change the model generated by CI or delivered in GitHub Actions. For reproducible CI integration, put the user's source GLB and/or verified rigged output under `assets/3d`, add a validation workflow, and compare animation frames on real Windows before promoting it to default.
