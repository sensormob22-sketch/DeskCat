## Содержимое

- Неизменённый оригинальный GLB и рабочая сцена `deskcat_v6_weight_handoff.blend` с упакованными текстурами.
- Localprep GLB как точная геометрическая основа source IDs сцены; включён дополнительно, чтобы специалист не сопоставлял маски с неверной нумерацией оригинала. Другие экспериментальные модели и Blender-сцены исключены.
- Два доступных **синтетических** стоячих референса. Исходное сидячее identity-изображение в репозитории отсутствует и не выдано за приложенное.
- [Русское ТЗ](BRIEF_RU.md) и [English brief/acceptance](ACCEPTANCE_EN.md): кошачья анатомия, ручная покраска, защита внешности, экспорт, приёмка и этапы оплаты без придуманных цен.
- Точные 17 baseline-костей с pivots/матрицами/иерархией, анатомические ориентиры, шесть масок, защищённые IDs и доэкспортные строки весов.
- CONTROL_POSES.json с 33 ранее измеренными позами этапа 9, четырьмя chain-контролями этапа 8 и двумя отдельными combined-контролями этапа 12. Углы и baseline-счётчики извлечены из существующих отчётов, не пересчитаны новой деформацией.
- **10 диагностических таблиц**: шесть масок/heatmaps этапа 9, один пример неуспеха C2 этапа 11, три сравнения cage этапа 12. Нет сотен повторяющихся кадров. Индекс поясняет цвета, камеры, окклюзию и ограничения base-color изображений.
- Исторические отчёты этапов 8–12 и выбранные измерения. Их старые ссылки на исключённые файлы могут не работать; корневой README/IMAGE_INDEX архива даёт актуальный компактный маршрут.
- MANIFEST.json с SHA-256/размерами всех вложений и исходным коммитом. Архив не содержит исполняемых установщиков, ключей или необходимых внешних текстур. Embedded UI сцены — существующая часть входного Blender-файла, явный запуск необязателен.

## Работа специалиста

Предусмотрены отдельные gates: диагностика и согласование анатомии → один локальный участок → остальные согласованные участки → экспорт и фактический runtime. За каждый gate принимать конкретные editable файлы, diff и контрольные виды/видео, а не только число костей или привлекательный rest-кадр. Стоимость, аванс, сроки, исправления и условия оплаты диагностики обсуждаются с исполнителем заранее.

После распаковки начать с BRIEF_RU.md / ACCEPTANCE_EN.md. Сцену v6 открывать как **непроверенный старт**, сохранять копию под новым именем. C2/cage — отклонённые примеры. Нужны ручной анатомический контроль, совпадающие веса UV-копий и сохранение защищённых вершин. Перестройка костей, расширение масок, ретопология и дальнейшая анимация требуют отдельно согласованного объёма работ. Реальную Windows 11 проверку заранее распределить между исполнителем и владельцем проекта.
