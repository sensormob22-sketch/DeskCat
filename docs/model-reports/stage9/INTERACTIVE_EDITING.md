# Как продолжить исправление без Blender на компьютере пользователя

## Что доступно сейчас

В текущем worker доступен Blender 4.3.2 **headless**. Не установлены Xvfb, x11vnc, websockify/noVNC; DISPLAY и WAYLAND_DISPLAY отсутствуют. Не предоставлены инструмент браузерной desktop-сессии и аутентифицированный пользовательский URL для этого worker. Проверки сохранены в [remote_capabilities.json](remote_capabilities.json).

**Полноценное интерактивное редактирование через браузер здесь сейчас недоступно.** Графический интерфейс, наведение мышью и настоящая покраска весов не проверялись. Регистрация панели и операторы выбора/поз проверены в headless, это не равнозначно GUI-сеансу. Установка одного noVNC не создаст маршрут доступа к облачному worker.

Платные рабочие станции не запускались, API-ключи не требуются. Штатный Blender не является браузерным редактором; WebGL-просмотр модели не заменяет его редактор весов.

## Возможные пути

| Путь | Нужен Blender на вашем Windows-компьютере? | Что требуется / статус |
|---|---|---|
| **Согласование масок по изображениям — рекомендовано сейчас** | Нет | Шесть таблиц, source IDs и явный JSON-план; последующее применение в headless только после согласования. Это **не ручная покраска**. |
| Передать `.blend` техническому художнику | Нет | У специалиста уже есть Blender 4.3.2 или совместимый новее. Открыть упакованную сцену и вручную покрасить ограниченные области; вернуть отдельный файл и журнал изменений. |
| Бесплатный самостоятельно обслуживаемый удалённый Blender | Нет | Нужен уже доступный вам Linux-компьютер/сервер с Blender, графической сессией и правами настройки доступа. [noVNC](https://github.com/novnc/noVNC) передаёт интерфейс через браузер; он не выполняет риггинг сам. Такой хост и доступ к нему в текущем задании не предоставлены; конфигурация не развёрнута и не проверена. |

Для последнего пути технически нужны X-сессия/Xvfb, Blender GUI, x11vnc или аналог, websockify/noVNC и защищённый маршрут (например SSH-туннель на собственный хост). В Windows 11 может использоваться встроенный OpenSSH-клиент, браузер показывает интерфейс удалённого Blender. API Tripo не нужен. Это предложение архитектуры, **не готовая ссылка для редактирования**; рабочего внешнего адреса мы не выдумываем.

## Согласование точных масок по изображениям

1. Выбрать одну таблицу и один столбец. На её **копии** отметить контур/точку и пожелание: например «зона 01, +15°, C1/C2, шире переход к тазу; не затрагивать заднюю лапу». Маркеры C относятся к source face IDs в подписи, полная 3D-точка записана в данных. Без новых фото можно указать номера граней/вершин текстом.
2. По отмеченным граням подобрать небольшой список source IDs из `data/region_masks.json`. `EDIT_*` — предел текущего кандидата; `REVIEW_*` — только контекст. Если нужно выйти за EDIT, сначала согласовать изменение самой маски, сохраняя protected IDs и принадлежность лапы.
3. Подготовить отдельный JSON на основе `proposal_template.json`: baseline hashes, область, человеческая аннотация, **точные строки весов** и все совпадающие UV-шовные копии. `baseline_vertex_weights` в масках даёт реальные float32 веса Blender, включая малые влияния, потерянные при экспорте GLB. Другие уже существующие влияния заморожены; не обнулять их скрыто.
4. Выполнить read-only проверку:

   ```bash
   .venv/bin/python tools/weight_handoff_contract.py \
     --proposal docs/model-reports/stage9/proposal_template.json \
     --masks docs/model-reports/stage9/data/region_masks.json \
     --source assets/3d/tripo/deskcat_calico_h25_v1_localprep.glb \
     --skin assets/3d/tripo/deskcat_calico_h25_v1_skinprobe_v6.glb \
     --scene assets/rigging/deskcat_v6_weight_handoff.blend
   ```

   Сейчас шаблон пуст: **0 изменений**, ничего не записывается. Проверяются hashes, зона, защищённые вершины, нормирование, максимум четырёх влияний, замороженные чужие влияния и идентичность шовных копий. Валидный JSON не доказывает красивую деформацию и не является согласием на применение.

5. Пользователь согласует конкретный diff: source IDs, старые/новые веса и область. Затем отдельная headless-операция может загрузить **копию** этой сцены, проверить hashes и source ID attributes, применить только перечисленные строки без envelope/сглаживания, сохранить новый `.blend`, повторить эти же 33 диагностические позы и 43 контроля этапа 8, показать до/после. На этапе 9 инструмент записи намеренно не создан. Экспорт skinprobe_v7 потребует отдельного согласования.

Такое согласование опирается на изображения и дискретные численные строки. Человек не проводит кистью по 3D-поверхности, поэтому это воспроизводимая точечная настройка по утверждённым маскам, **а не полноценная ручная покраска**.
