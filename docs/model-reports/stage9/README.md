## Подготовленная сцена

Скачать [`deskcat_v6_weight_handoff.blend`](../../../assets/rigging/deskcat_v6_weight_handoff.blend) — примерно 22 MiB, Blender **4.3.2**, все изображения упакованы внутрь; внешние текстуры и дополнения не нужны. [Аудит файла](data/scene_audit.json) содержит SHA-256 сцены и исходных моделей.

Внутри:

- `WORKING_V6_UNCHANGED_WEIGHTS`: исходные 58450 вершин / 100790 граней localprep, 17 настоящих костных групп с исходными весами Blender v6. Не импортировали заново GLB с потерей малых весов и не запускали генератор новых envelope.
- `V6_17_BONES_UNVERIFIED`: прежние асимметричные цепочки, положения суставов и иерархия v6; кости поверх модели и отдельные axis guides.
- Скрытая коллекция `READ_ONLY_ORIGINAL_REFERENCE_TOGGLE_VISIBILITY`: импорт оригинального GLB для сравнения, выбор и трансформации заблокированы. Это Blender-конвенция защиты, а не неизменяемое право доступа.
- `EDIT_*`: ограниченные проблемными/сильно деформированными гранями и тремя соседними топологическими кольцами маски; `REVIEW_*`: широкий анатомический контекст. Эти группы **не являются костями** и не влияют на Armature.
- Четыре отдельные подмаски `EDIT_wrist_FL`, `EDIT_wrist_FR`, `EDIT_hock_HL`, `EDIT_hock_HR`, размеченные расстоянием по связной сетке от четырёх реально измеренных подошв, без зеркалирования.
- `PROTECT_HEAD_EYES_EARS`, `PROTECT_SOLES`: замороженные выборки. У `root` и групп защиты включён lock. Все 10459 защищённых source IDs исключены из EDIT.
- Point attributes `source_vertex_id`, Face attributes `source_face_id` и Boolean `PROBLEM_*`, исходные UV и `HEAT_*` цветовые слои для просмотра влияний. Они не подключены вместо оригинального материала и не перекрашивают шерсть.
- Text-блоки `REGION_MASKS.json`, `POSE_REVIEW.json`, `READ_ME_FIRST.txt` и переносимая панель `DESKCAT_REVIEW_UI.py`. Внешний JSON дополнительно содержит точные baseline-веса 5330 различных редактируемых вершин.

### Открытие специалистом

1. Открыть `.blend` в Blender 4.3.2. Сцена сохранена в rest, без animation actions и keyframes.
2. В рабочем пространстве Scripting открыть Text `DESKCAT_REVIEW_UI.py` и **явно Run Script**. Автозапуск при открытии файла не нужен. В 3D View → Sidebar (`N`) появится **DeskCat**.
3. Выбрать область → `Select editable review mask`. Выбираются source vertices EDIT, активируется настоящая костная группа. Затем перейти в Weight Paint; маскирование вершин включено. Для FL/FR/HL/HR можно выбрать соответствующую отдельную группу и кость через Object Data.
4. Выбрать rest / ±10 / ±15 / hold в панели → `Show selected diagnostic pose`. Оператор меняет только проверяемую позу, без ключей, весов и экспорта. Перед сохранением вернуть rest.
5. Не рисовать по лицу, глазам, ушам или подошвам; не менять UV/материалы. Сохранять результат в **другой** `.blend`. GUI-lock может быть отключён человеком, поэтому итоговый source-ID аудит обязателен.

Панель и выбор всех шести областей проверены headless, как и повторное вычисление +15° после открытия сохранённого файла. Настоящая покраска мышью и работа GUI в графической сессии не проверялись.

Сумма размеров областей не равна 5330: маски пересекаются на стыках. `REVIEW_*` шире EDIT и не означает наличие дефекта на каждой вершине. В таблицах запястий/скакательных изолированные пробы двигают **обе соответствующие цепочки**, heatmap показывает сумму их двух distal-влияний; исходная асимметрия сохранена.

Heatmap: синий 0, зелёный .5, красный 1. Красные контуры — новые строгие пересечения в этой области, не старые 16 пар. C1/C2/C3 — вычисленные точки пересечения с source face IDs в нижней подписи; это проекции без проверки окклюзии, скрытая поверхность также может отмечаться. Source IDs относятся к localprep/рабочей Blender-сетке, а не к переупорядоченному GLB-экспорту. Полные точки, пары и углы в [pose_review.json](data/pose_review.json), точные камеры и подписи в [sheet_metadata.json](sheets/sheet_metadata.json). Число `global` включает весь меш, `in zone` — пересечения, касающиеся отмеченных граней этой области.

На таблицах PE=pelvis, LU=lumbar, TH=thoracic, TA=tail_base, SH=shoulder, EL=elbow, WR=wrist, HI=hip, ST=stifle, HO=hock. FL/FR/HL/HR — передняя левая/правая, задняя левая/правая. Углы записаны в градусах; это контролируемые пробы, не сертифицированный диапазон движения кошки.

## Что проверено

[Повторное открытие файла](data/reopened_scene_audit.json): координаты и UV совпали точно, source vertex/face IDs сохранились; digest 17 float32 костных групп совпадает с исходной сценой v6. Три исходных texture hashes найдены в packed images, внешних зависимостей 0. Недеформирующие axis guides совпали с фактическими головами костей (ошибка 0 в rest и проверяемых +15° позах); исправлялось только размещение этих вспомогательных указателей, не скелет. Операторы панели выбирают точные маски и воспроизводят +15° всех областей. Новый GLB не экспортировался; GLB Validator на этапе 9 повторно не запускался, результат этапа 8 не выдаётся за новую проверку сцены.

Важная обнаруженная разница: Blender GLB exporter 4.3.2 (`primitive_extract.py`, `min_influence=0.0001`) отбрасывает веса **<=0.0001**. Между исходной сценой и существующим GLB v6 отличается 7530 source vertices, потеряно 12343 положительных влияния; максимальная разница компонента .000179112. На этапе 9 их **не «починили» и не округлили**: восстановлена исходная Blender-сцена, а оба baseline явно различаются. Для будущей правки использовать `baseline_vertex_weights` из масок, не реконструированные веса экспортированного GLB.

Проверки выполнялись в Linux, Blender 4.3.2 headless, Python 3.12, Panda3D 1.10.15/panda3d-gltf 1.3.0, Qt offscreen, llvmpipe. **86 тестов прошли (9 новых), 22.71 с**. [Отчёт тестов](test_results.json). Проверка Windows GUI, браузерной покраски, полноценного PBR и красивой деформации не заявляется.

## Повторить проверки / подготовку

Готовая `.blend` — основной переносимый результат. Исходная `artifacts/stage8_v6/experimental_probe.blend` сохранена только в текущем worker; для повторного получения **доэкспортных** v6 весов на новой машине использовать поставленную `.blend`, а не GLB с отброшенными малыми влияниями.

```bash

.venv/bin/python -m pytest -q
```

В `.blend` embedded Text сохранены маски/позы; внешний JSON также содержит позднее добавленные точные baseline-строки. Diagnostic snapshots в `artifacts/stage9_handoff_delivery/` игнорируются Git; в репозитории только готовая сцена, шесть таблиц, измерения и документация.
