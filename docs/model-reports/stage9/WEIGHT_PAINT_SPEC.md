# Спецификация точечной настройки — ещё не применена

Основа: **исходные Blender-веса v6 до экспорта**, сохранённые в `deskcat_v6_weight_handoff.blend`. Геометрия localprep, исходные UV и три оригинальные текстуры неизменны. Это план для человека, а не очередной генератор весов.

[Машинная версия ограничений и целей](weight_paint_spec.json).

## Общие ограничения

- `EDIT_*` — кандидаты для локальной правки; `REVIEW_*` — более широкий контекст. Наличие вершины в маске не предписывает менять её вес. `PROBLEM_*` отмечает измеренные новые пересечения; площадь <.5 или >2 дополнительно использована при выборе соседней области.
- **Все 10459 `protected_source_vertex_ids` заморожены:** мордочка, глаза, уши, консервативная верхняя часть головы и четыре опорные заплатки. Сохранить их текущие веса v6, координаты и UV. Корневая группа и группы защиты первоначально заблокированы; запрет проверяется по source IDs, а не только по состоянию GUI.
- Защита головы расширена относительно старой маски этапа 7: прежнее `X<−.35,Y>.30` плюс `X<−.275,Y>.41`. Это консервативная область с запасом, не сертифицированная анатомическая сегментация. Существующие слабые влияния корпуса на некоторые верхние вершины **не исправлены**; заморозка сохраняет baseline, а не доказывает отсутствие их старой деформации.
- Сохранить рисунок шерсти, длину хвоста, форму лап и исходную асимметрию. Не редактировать геометрию, UV, нормали, материалы или пиксели текстур. Не выпрямлять ноги и не зеркалировать цепочки.
- До четырёх деформирующих влияний, каждое в [0,1], сумма 1 с допуском 1e-6. Совпадающие по позиции UV-шовные копии получают одинаковые веса с допуском 1e-7.
- Менять только перечисленные ниже влияния. Остальные уже существующие влияния на выбранной вершине сохранять **точно по Blender baseline**, даже если они меньше порога GLB-экспортёра. Новое влияние соседней лапы запрещено.
- Не назначать всей маске одинаковые веса. Переход распределять несколькими рядами соседних вершин вдоль реальной поверхности. Каждый предложенный ряд — явные source IDs и полная нормированная строка весов; универсальная X/Y-маска, новый envelope и автоматическое сглаживание не являются согласованной правкой.

## Направления правки

| Область | Что может менять человек | Желаемое распределение / запрет |
|---|---|---|
| Основание хвоста → таз | `pelvis`, `tail_base` | На коже крупа влияние хвоста 0; на хвостовой коже переход pelvis→tail_base плавный вдоль её поверхности, без сжатого поперечного кольца. Дистальная часть хвоста и полосы остаются прежними. Точный проксимальный контур требует согласования, текущая связная маска не анатомическая истина. Не добавлять tail-вес на бедро и подошвы. |
| Грудной отдел / живот | `thoracic`, `lumbar`, при необходимости `root` | Разнести передачу движения позвоночника и кожу живота; уменьшить концентрацию сжатия у передних цепочек. Существующие влияния плеч/ног вне выбранной операции сохраняются. Не сдвигать проблему в шею, мордочку или задние ноги. Root исходно locked: специалист может разблокировать его лишь после применения вершинной маски; защищённые source IDs остаются запрещёнными. |
| Левое бедро | `pelvis`, `hip_HL`, `stifle_HL` | Плавная таз→бедро→колено передача на действительной левой конечности. Отдельно разобрать хвостовые/паховые вершины рядом с (.27,.22,.03), захваченные hip_HL: не считать весь кластер «мышцей бедра». Изгиб −15° важнее оптимизации только +15°; правую цепочку не копировать. |
| Правое плечо / передняя лапа | `thoracic`, `shoulder_FR`, `elbow_FR`, `wrist_FR` | Уточнить стык грудь→плечо, затем нижнюю границу лапы. Большинство новых пар плечевой пробы находится у передней правой опоры, поэтому не исправлять только pivot плеча. Левая передняя цепочка заморожена вне отдельной операции. |
| Запястья → подошвы | Для FL: `shoulder_FL`,`elbow_FL`,`wrist_FL`; для FR соответствующие FR | На защищённой подошве оставить baseline жёсткого блока; расширять плавный переход **выше** её границы, не внутри опоры. Изменять только кости своей лапы. Для работы использовать отдельные `EDIT_wrist_FL` / `EDIT_wrist_FR`. |
| Скакательные → подошвы | Для HL: `hip_HL`,`stifle_HL`,`hock_HL`; для HR соответствующие HR | Аналогично: сохранять опору, распределять изгиб выше неё и контролировать силуэт скакательного сустава. `EDIT_hock_HL` / `EDIT_hock_HR` различаются по реальным компонентам опоры, не зеркалированием. |

Маски областей пересекаются на переходах; это **не разрешение складывать две независимые правки**. Согласовывать одну область и одну небольшую операцию за раз, затем повторять контрольные позы.

## Как принимать правку

1. До/после — те же rest, ±10°, ±15° и два комбинированных holdout каждой таблицы; локальный и глобальный подсчёт новых пар отдельно от исходных 16. Первоначальные пересечения не требуется автоматически уничтожать.
2. Проверить точные source face pairs и точки пересечений, площадь граней и P1/P5/P50/P95/P99 растяжения, геометрическую непрерывность совпадающих шовных копий. Сохранить прежние консервативные критерии этапа 8; перцентили дополняют экстремумы, а не скрывают их.
3. Снижение числа пар без улучшения силуэта, складок и формы опоры — недостаточно. Не допускать новых регрессий в противоположном направлении и в соседних областях; отсутствие новых пар само по себе не делает риг production-ready.
4. Проверить мордочку, глаза, уши, полосы хвоста и пятна на одинаковых камерах, исходные UV/texture hashes и полный список изменённых весовых строк. Защищённые строки должны остаться прежними.
5. После отдельно согласованного экспорта проверять **и Blender, и фактический GLB**: экспортёр 4.3.2 отбрасывает веса `<=0.0001` и нормирует оставшиеся. Тесты только до экспорта не доказывают сохранность поведения в Panda3D.

На этапе 9 ни одна из этих весовых правок не применена. В контракте и примерах нет команды записи новых весов или экспорта skinprobe_v7.
