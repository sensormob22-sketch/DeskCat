У всех четырёх площадь воображаемой треугольной крышки и остаток коллинеарности равны 0 в исходных координатах. Предложение: подразделить существующую грань, а не добавлять крышку. Оно требует проверки принадлежности ребра поверхности тела и сохранения ориентации. D07 имеет большой разброс соседних нормалей (~86.6°): анатомическую складку нельзя сглаживать. D04 почти коллинеарен (остаток 2.24e-9), D09 содержит перекрывающиеся цепочки без единого длинного ребра: никаких допусковых weld/cap по умолчанию.

## Отделение декоративных кандидатов

Для D01/D02/D11/D12/D13 — именованные малые partitions хвоста; D03/D08/D19 — таза; D16 — живота; D20/D23 — шеи; D10/D21/D22 — мордочки. Полные конкретные списки граней каждой partition сохранены в JSON. Отделение означает только исключение из solver-body и дублирование временных junction-вершин по веерам, **не удаление исходной шерсти**. P11 — маленькая закрытая группа: её нельзя автоматически объявить плоским листом.
