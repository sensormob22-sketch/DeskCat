# Test asset

`test_cat.glb` is original DeskCat test geometry, dedicated to the public domain
under CC0-1.0. Generated deterministically with `python tools/generate_test_cat.py`.
It contains one skinned mesh, six joints, and seven two-second test clips.
These clips demonstrate skinning and blending; sit/groom/etc. are diagnostic
motions, not anatomically accurate cat animations. No Tripo calls or external assets.
